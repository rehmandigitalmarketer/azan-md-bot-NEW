## 🚀 How to Deploy on Vercel (100% Free - 2 Minutes)

### Option 1: Deploy via GitHub (Recommended)
1. Go to [GitHub.com](https://github.com/) and create a new repository (e.g. `azan-md-pairing-portal`).
2. Upload the contents of this `azan-md-vercel` folder to your GitHub repo.
3. Open [Vercel.com](https://vercel.com/) and sign in with GitHub.
4. Click **"Add New" > "Project"** and select your `azan-md-pairing-portal` repository.
5. Click **"Deploy"**!
6. In 30 seconds, Vercel will give you a live domain like `https://azan-md-bot.vercel.app`!

---

### Option 2: Deploy via Vercel CLI
```bash
# 1. Install Vercel CLI globally
npm i -g vercel

# 2. Navigate to directory
cd azan-md-vercel

# 3. Deploy
vercel
```
